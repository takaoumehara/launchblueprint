### 入り方3案（決済手数料は 2026-10-26 に公式ページで確認）
| | USファースト | 日英同時 | MoR決済先行 |
|---|---|---|---|
| 良い点 | 作る量が最小。PH/HN と相性がよい | 両市場を同時に比べられる。i18n の同時更新はAIで安い | 各国の税の登録と納税を MoR が負う。請求の問い合わせも MoR |
| 悪い点 | 日本の強みを使えない。後から日本語化すると作り直しが出る | ローンチ作業が2倍 | 手数料 5%+50¢（$10 の商品なら約10%）。決済の名義が MoR になる |
| リスク | 後付け i18n でハードコード文字列が残る | 両方とも中途半端になる。日本の税と特商法を自分で確かめる必要 | 審査落ちや規約変更、ロックイン |
| 無料 | Stripe 2.9%+30¢ | i18n とAI翻訳は無料 | 月額0、5%+50¢/件 |
| $5／$10 | 同左 | $10：ネイティブ確認を一部外注 | 同左 |
| $100 | ＋売上税（Stripe Tax Basic 0.5%） | 全面的なネイティブレビュー＋少額広告 | 同左（量が増えたら個別料金を相談） |

**おすすめ（NY LLC の小さなスタジオ、日英のデジタル製品の場合）**：コードは初日から日英にし、決済は MoR（Paddle か Lemon Squeezy）にします。
- 理由1：後から i18n を入れるのがいちばん高くつきます。
- 理由2：$10 の商品で比べると、Stripe＋Tax Basic は約7.4%（米国内カードの場合。税の登録と申告は自分でやる）、MoR は約10%です。差は1件あたり30¢前後で、税の手間と責任を MoR に移せることのほうが大きいです。
- 乗り換えの目安：手数料の差が税の外注費（Stripe Tax Complete＋会計士）を上回ったら、Stripe に移ります。

出典（2026-10-26 確認）：
- https://stripe.com/pricing ：国内カード 2.9%+30¢、国際カード +1%
- https://stripe.com/tax/pricing ：Tax Basic は 0.5%/件 または 50¢/件。Tax Complete は月額で1年契約、金額は未取得
- https://www.lemonsqueezy.com/pricing ：5%+50¢。米国外の取引などに追加手数料あり
- https://www.paddle.com/pricing ：5%+50¢。追加手数料なしとうたう。$10 未満の商品は個別に相談
