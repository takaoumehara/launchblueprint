# ブループリント v2 まとめ

**今のスキル**: `launch-blueprint`（/workspace/launch-blueprint）。中身はすでに濃い（料金・無料枠の商用可否・法務・死亡/休眠アカウントなど17項目のリスク表）。足りないのは「どこまで考えるかを最初に決める仕組み」と「変更の影響が見える地図」。

**v2 で足したこと**
1. 最初に最大10問の質問 → 深さを T0試作 / T1社内ツール / T2公開(無料) / T3有料・規制あり から選ぶ。不要なブロックは「スキップ（理由）」と書くだけ。考えすぎて止まるのを防ぐ。
2. 「変えると高くつく決定」を最初にロック（ホスト、DB、ログイン方式、ドメイン、ブランド名、デザイン方向、AIツールの役割）。途中で変えるときは影響範囲・コスト・OK が必要。
3. 国別ルール：GDPR、英国GDPR、EU/英国の代理人（Art.27、例: Prighter 月€39〜、DataRep 年€150〜）、米国州法・COPPA、日本の個人情報保護法・特商法、アプリストア、アクセシビリティ（EU アクセシビリティ法）、サブスク解約ルール、EU AI法。
4. アカウントの一生：名前変更、メール変更、削除、乗っ取りと復旧、死亡・失踪・障害時（Facebook の追悼アカウント管理人のような仕組み）、未成年。
5. 規約での責任分担と、弁護士が必要な場面。オンラインの選択肢（Termly、iubenda、LegalZoom、Rocket Lawyer、弁護士ドットコム）。
6. コストと AI クレジット予算、「安いものから確認」（文章→声→映像）。
7. 運用・サポート、分析、撤退・移行計画。

**見える化のおすすめ**: blueprint.yaml（ブロック同士を「依存」「影響」でつなぐ）を元に、1画面のノード図を描く。1つ変えると影響するブロックが赤くなる。AI は変更前に必ずこの YAML を読む。
