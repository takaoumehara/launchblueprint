# ブランド・ブループリント（要約）

見た目だけでなく、言葉・声・動き・音・空間まで、ひとつの「ブランドの人格」から作るためのスキルです。画像AI・コピー・ElevenLabs の声・アニメーション・効果音が、どのツールを使ってもブレないようにします。

- **段階（B0〜B3）**：試作なら名前・3語の人格・色・書体だけ。公開ブランドなら動き・音・接点まで。店舗や車両があるなら香り・照明・素材・動線まで。要らない項目は理由を書いて飛ばします。
- **戦略**：ミッション、ビジョン、バリュー、ブランドプロミス、ポジショニング、Brand Key、カプフェレのプリズム。
- **人格と声**：アーカーの5つの人格で採点し、トーンを「カジュアル↔丁寧」「穏やか↔元気」などのスライダーで決めて、場面ごとの例文を日英で作ります。
- **UXライティング・命名**：ボタン、エラー文、用語集、禁止語、名前の候補と商標チェック。
- **アイデンティティ**：ロゴ一式、ファビコン、アプリアイコン、ロゴアニメ・オープニング、色・書体・レイアウトをデザイントークン（DTCG形式）で。
- **アートディレクション**：写真とイラストの方向性。AI画像は毎回同じ「スタイル文」と参考画像を付けて、一貫性を保ちます。
- **動き**：ホバー、押したとき、クリック、ローディングなど超細かいインタラクションまで定義。動きを減らす設定にも対応します。
- **音と声**：UI効果音、日本のCMのようなサウンドロゴ、ElevenLabs の声選び（3声で聞き比べ、設定と読み方辞書を記録）。音声は台本を文章で承認してから作ります。
- **フィジカル（任意）**：香り、照明、素材、制服、売り場の動線（カルディ型の「発見」か、まっすぐな「効率」か）。
- **360°タッチポイント**：業種別テンプレートつき。芝刈りなどの地元ビジネスなら、頼まれなくてもトラックのラッピング、制服、庭先看板、ドアハンガーのモックを出します。
- **トレンド調査**：今月の事例を集めて、取り入れる・アレンジする・見送るを判断。
- **つながった図**：`brand.yaml` の各ブロックが製品側のブループリントと線でつながり、人格やロゴを変えると作り直す素材とコストが一覧で出ます。

ファイル：`brand/SKILL.md`（本体）、`brand/template.md`（記入用）。
