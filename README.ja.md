# launch-blueprint（日本語まとめ）

## 何をするスキルか
新しい商品や大きな機能を作るとき、**コードを書く前に**、AIが会社として必要な全部の面を一枚の「ブループリント」にまとめます。頼まれていないことも含めて見ます。オーナーが思いつかなかった論点を、問題になる前に先回りして出すのがこのスキルの仕事です。

## 先回りのやり方
- 最初に、そしてオーナーから新しい事実が出るたびに、「すべてを変える事実」を短くまとめて聞きます：オーナーの居住国、法人の登記国、お客さんと利用者の所在地、お金が動くか（誰と誰の間か：運営、出品者、購入者）、利用者が他人に見えるコンテンツを公開するか、未成年が使う可能性、AIが利用者データを処理するか
- どの提案にも、おすすめ案と代替案を出し、費用・法律・運用・集客・実装・UXの6つの角度で確認します
- 決めたことは日付つきで「決定ログ」に残します
- 事実が変わったら（引っ越し、課金開始、国外からの最初の利用者など）、それに依存していた決定を見直します

## ブループリントの中身
- 冒頭：「すべてを変える事実」と「地域の表」（地域ごとに「提供する／制限つきで提供する／登録と決済を止めて公開ページだけ見せる」のどれかと、その理由と義務）
1. 商品とお客さん（誰の、どんな困りごとを、いくらで。最初の1業種・1地域・1プラン。言わないこと、約束しないこと）
2. 値段と原価（1件あたりの原価、月の固定費、無料で出すものの上限、損益分岐点、MoRか自前の税登録か）
3. 技術の構成（置き場所は原則1つ。サービスごとに「無料プランで商用利用できるか・上限・超えたらどうなるか・月額・確認日・規約URL」の表。無料・趣味プランは最初の決済で商用に変わること。1日のデプロイ上限とプッシュの作法、プレビュー環境とDBブランチの上限、環境判定は未設定なら本番の厳しい側に倒すこと、エッジ・サーバーレスDBの制限をテストで再現すること、本番に近い遅延でテストを回すこと、メールの送信上限と到達性、AI機能の上限と代替プロバイダ、非ラテン文字のURLやCJKフォント、秘密の鍵、費用暴走の防止と停止スイッチ、バックアップと復元訓練、監視）
4. 法律とお金（法人、登録代理人、自宅でない住所、カード明細の名前と合わせる屋号、税番号、銀行、年次の届出、サイバー保険、売上税/VAT/MoR、責任を限定する規約（弁護士確認）、プライバシー、返金、アクセシビリティ、A2P 10DLC、CAN-SPAM、DMCA、商標の区分、業者アカウントは会社名義と仕事用メールで、断る業種、弁護士に見てもらう所）
5. 集客とブランド（名前と商標、ドメイン、UI文言のブランドボイス規則、入口→申込→継続、最初の10件）
6. 運用（手作業の時間、承認が要ること、問い合わせ窓口、定期ジョブが止まったら誰に通知するか）
7. ライフサイクル・リスク・セキュリティ（必須）：休眠アカウント、解約・返金、データの書き出しと削除、亡くなった利用者、違法・著作権コンテンツの削除、チャージバック、障害と補償の上限、責任の上限と訴訟対策、未成年、各国の個人情報法と地域、料金・規約変更の事前通知、サービス終了、乗っ取り対策、情報漏えいの通知、乗り換えの計画、10倍・100倍の費用、利用者間のお金（出品者や主催者の取消・退会時の返金、残す記録、払い出し、手数料免除、退会後も残る領収書）、AI機能（上限、代替、費用、送るデータ、出力の確認、地域の規制）。セキュリティはさらに：OAuth連携を使った乗っ取りと復旧、メール変更の通知と取り消し、サポート窓口での本人確認、認証情報を含まないバックアップと復元訓練、ホストごとのヘッダーの信頼、URL取得機能のSSRF対策、リンク安全性APIの利用規約、定期ジョブの無言停止
8. オーナーのやること一覧（順番、だいたいの日数、何が進むようになるか）
- 末尾：決定ログ（日付、決定、選ばなかった案、前提にした事実、見直す条件）

## 地域ごとの確認（`references/jurisdictions.md`）
- EU/EEA：GDPR（処理の根拠、処理者とのDPA、国外移転とSCC、EU外の管理者の代理人、本人からの請求、漏えい通知の期限）、Cookie同意（アナリティクスやセッション録画は同意が必要）、デジタルサービスの VAT（EU外の売り手は最初の1件から。非連合OSS、またはMoR）、デジタルサービス法（利用者コンテンツを置くなら通知と対応、理由の説明、連絡窓口、透明性）、EU AI法の透明性義務、デジタルコンテンツの撤回権、欧州アクセシビリティ法
- 英国・スイス：それぞれ独自のGDPR相当法とVAT
- 米国：州ごとのSaaS売上税と経済的ネクサス、州のプライバシー法と閾値、自動更新と解約のルール（州法、FTC）、COPPA、CAN-SPAM、A2P 10DLC、DMCA代理人
- オーナーの居住国：その市場を対象にするなら消費者保護と商取引の表示義務が及ぶ。対象にするかどうかを決めて書く
- MoRか自前の税登録かは、費用・法律・運用のトレードオフとして決める
- 地域の遮断はIPとカード発行国で行うが、VPNなどで抜けられる。遮断中でも、登録してしまった人からのデータ請求などは守る

## ルール
- 推測しない。分からないことは「NEEDS CONFIRMATION（要確認）」にして、まとめて質問する
- 法律や閾値は「一次情報と弁護士で確認」を必ずつける
- 決めたことには、おすすめ案と代替案と理由を1行ずつ、6つの角度で
- 費用は数字で。今・10倍・100倍
- 外部サービスの料金と規約は、毎回その場でページを開いて確認する。上限は変わるので確認日を書く
- 見直しの時期：公開前、10件目のお客さん、値段を変える前、サービスを足すとき、事故のあと、そして「すべてを変える事実」が変わったとき

## なぜ作ったか
無料プランが商用利用禁止のホストで作ってしまい後で移行が必要になった、費用の上限がそのホストでは効かない作りだった、公開直前に住所や規約の空欄が見つかった——という実例（匿名化）から作りました。後の見直しでは、EUの利用者、デプロイ上限、認証情報を含んだバックアップ、OAuth連携による乗っ取りも、誰も考えていなかったことが分かりました。
