# launch-blueprint（日本語まとめ）

## 何をするスキルか
新しい商品や大きな機能を作るとき、**コードを書く前に**、AIが会社として必要な全部の面を一枚の「ブループリント」にまとめます。頼まれていないことも含めて見ます。

## 埋める8つの欄
1. 商品とお客さん（誰の、どんな困りごとを、いくらで。最初の1業種・1地域・1プラン。言わないこと、約束しないこと）
2. 値段と原価（1件あたりの原価、月の固定費、無料で出すものの上限、損益分岐点）
3. 技術の構成（置き場所は原則1つ。サービスごとに「無料プランで商用利用できるか・上限・超えたらどうなるか・月額・確認日・規約URL」の表。秘密の鍵、費用暴走の防止と停止スイッチ、バックアップ、監視）
4. 法律とお金（会社、自宅でない住所、EIN、銀行、保険、売上税/MoR、規約、プライバシー、返金、アクセシビリティ、A2P 10DLC、CAN-SPAM、DMCA、断る業種、弁護士に見てもらう所）
5. 集客とブランド（名前と商標、ドメイン、入口→申込→継続、最初の10件）
6. 運用（手作業の時間、承認が要ること、問い合わせ窓口）
7. ライフサイクルとリスク（必須）：休眠アカウント、解約・返金、データの書き出しと削除、亡くなった利用者、違法・著作権コンテンツの削除、チャージバック、障害と補償の上限、責任の上限と訴訟対策、未成年、各国の個人情報法、料金・規約変更の事前通知、サービス終了、乗っ取り対策、情報漏えいの通知、乗り換えの計画、10倍・100倍の費用
8. オーナーのやること一覧（順番、だいたいの日数、何が進むようになるか）

## ルール
- 推測しない。分からないことは「NEEDS CONFIRMATION（要確認）」にして、まとめて質問する
- 決めたことには、選ばなかった案と理由を1行ずつ
- 費用は数字で。今・10倍・100倍
- 外部サービスの料金と規約は、毎回その場でページを開いて確認する
- 見直しの時期：公開前、10件目のお客さん、値段を変える前、サービスを足すとき、事故のあと

## なぜ作ったか
無料プランが商用利用禁止のホストで作ってしまい後で移行が必要になった、費用の上限がそのホストでは効かない作りだった、公開直前に住所や規約の空欄が見つかった——という実例（匿名化）から作りました。
