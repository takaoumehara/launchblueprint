## 文字
- 見出しは text-wrap: balance、説明は pretty。数字と価格は tabular-nums。
- 大きさ：26 / 22 / 16 / 14 / 12.5 / 11。行間：見出し 1.15、本文 1.55。

## 面
- 暗い面に影は使わず、1px の白い輪（oklch 白 10%）を使う。細い線は 2x 画面で 0.5px。
- 形（2026-10-26 v3 で改訂）：**角丸はすべて 0**。使ってよい形は「真四角・長方形」と「真円」だけ。楕円・ピル・角丸長方形は禁止。

## 動き
- transition: all は使わない。動かすのは transform と opacity だけ（輪は box-shadow を一緒に指定）。
- ease は cubic-bezier(.23,1,.32,1)、150〜300ms。prefers-reduced-motion では止める。

## 明るい／暗い表示（2026-10-26 改訂：モダンなツール調）
- 共通トークン：`bp-tokens.css`（OKLCH）。テーマ：`bp-theme.js`（`<head>` で同期読み込み＝ちらつきなし。保存 → OS → 明るい の順）。`?theme=dark` で確認用に切替。
- **明るい表示＝純白の面＋冷たいニュートラルグレー**（色相265・彩度0.006以下）。クリーム色・暖色の下地は使わない。
- **暗い表示もニュートラル**（琥珀は廃止）。面は3段（bg → sf → sf2）で、上の面ほど明るい。影は使わず 1px の輪。
- **強調色は1つだけ：インディゴ**（塗り `--ac`、文字 `--ac-tx`＝白地で4.5:1以上）。選択・おすすめ・トレース・主ボタンは全部これ。緑・赤・黄は「意味」（OK・危険・要確認）にだけ使う。
- 選択の光（`--glow`）：1pxの強調色の輪＋4pxの薄い外輪＋ごく弱い影。大きな発光はしない。
- 文字：Geist → Inter → システム、和文は Hiragino / Noto。見出しは字間 −0.025em（大）／−0.015em（中）、太さ600。数字は等幅数字。
- 線：1px（高解像度で0.5px）のアルファ線。影は3層の薄いもの（`--shadow-1/2`）。角は 0（`--r-*:0`、円だけ `--r-circle:50%`）。
- アイコン：状態は記号（●○×）ではなく 6px の点（塗り＝採用、輪＝候補、薄い＝未評価）。絵文字は使わない。
- フォーカス：2px の実線（文字色）＋2pxの余白。強調色にはしない。
- 動き：120〜260ms、ease-out。切替中はトランジションを止める。動きを減らす設定では移動をやめ、色と透明度だけ残す。

## v3 の見た目のルール（2026-10-26）
- **形**：radius 0 の四角と真円だけ。状態の点・ポート・スライダーのつまみ＝真円。カード・ボタン・タグ・入力欄＝四角。楕円とピルは使わない。
- **ノード**：ComfyUI 風。200×56 の四角、左端 3px の状態バー、半径 4 の円ポート、細いベジェ線。押すと右に説明カード（380px、四角）が開き、最後の行にデータの場所（`data/canvas.json → nodes[id=…]`）を出す。
- **線の濃さ＝意味**：候補は薄い線を 5 本束ねる、決まった流れは 1 本 .55、選んだ道筋（トレース）はアクセント色で流れるアニメ。線の本数＝量（ルールの強さ・責任の数・金額）。
- **画面ごとの図**：キャンバス＝ノード図／比較＝責任のサンキー／ルール＝系譜ファン（出どころ→ルール→効く所）／作る vs 買う＝費用のサンキー（スライダーで変わる）／カタログ＝点の集まり（カバー率と鮮度：塗り＝採用、輪＝候補、薄い輪＝未評価、赤＝不採用、中が抜けた点＝出典未確認）。
- **色の面**：採用など「決まったもの」はアクセント色のベタ面に背景色の文字（明暗どちらでも読める）。
- **動き**：線のホバーで近いものだけ光り、他は薄くなる。流れ・ズーム・ドロワーは `prefers-reduced-motion` で止める。`transition: all` は使わない。
- **明暗**：白（純白）と暗い面の両方。`?theme=light|dark` で固定できる。
- **マシンリーダブル（必須）**：画面は YAML → `data/*.json` から描く。各画面に同じ JSON を `<script type="application/json" id="bp-data">` で埋め込み、`<link rel="alternate" type="application/json">` と画面右上の `/data/…json` リンクで出す。一覧は `llms.txt`。生成は `python3 catalog/_build_screens.py`。
